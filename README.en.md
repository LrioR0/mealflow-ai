# mealflow-ai

#### Description

A government-canteen operations agent that orchestrates deterministic tools to plan menus and procurement from diner counts, inventory, dietary constraints, costs, and anonymous public PC kiosk feedback.

#### Project status

The repository is preparing a V1 demo to be built by Lrio and Colin in 3–4 days during the National Day holiday and demonstrated afterward. No runnable application has been committed yet. The Chinese documentation is the source of truth: [product baseline](docs/产品定稿方案.md), [technical development document](docs/技术开发文档.md), and [3–4 day plan](docs/三天开发计划.md).
