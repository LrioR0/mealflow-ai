# 部署与运行手册

## 开发环境

目标环境：Python 3.12+、Node.js 20+、Docker Desktop（可选）。Day 1 建立目录后，预期命令为：

```text
cd apps/api && pip install -r requirements.txt && uvicorn app.main:app --reload
cd apps/web && npm install && npm run dev
```

实际命令以提交的依赖文件为准；当前仓库尚未提供应用代码，不可执行上述命令。

## 配置

从 `.env.example` 复制为 `.env`，至少设置 `DATABASE_URL`、`LLM_PROVIDER`、`LLM_API_KEY`、`LLM_MODEL`、`CORS_ORIGINS`。`.env` 永不提交。开发期可以不配置 LLM，此时 API 必须启用规则结果回退。

## 容器化与排障

Day 3 时间充足时提供 `docker compose up --build`，服务至少包含 `api` 与 `web`；MVP 的 SQLite 通过命名卷持久化。启动失败按以下顺序排查：`docker compose ps`、`docker compose logs api`、环境变量、端口冲突、数据库卷权限。生产迁移 PostgreSQL 前不得将 SQLite 用于多实例并发写入。
