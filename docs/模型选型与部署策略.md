# MealFlow 模型选型与部署策略（定稿）

## 1. V1 冻结决策

V1 只通过互联网调用国产大模型 API，不下载模型、不使用 Ollama/vLLM、不配置 GPU、不承担任何本地或内网模型部署工作。

- 主模型：通义千问 API。
- 备用模型：DeepSeek API。
- 可替换候选：智谱 API；只有团队已经具备可用凭据且完成固定用例验证时才切换。
- 演示前 24 小时冻结主模型名称、接口地址和提示词模板，演示当天不临时升级模型。
- 所有 V1 调用只使用演示种子数据，不发送真实政府单位、人员或生产数据。

选择千问作为默认主模型不是产品绑定。V1 仍使用统一 Provider 接口，主模型不可用时可以人工切换 DeepSeek；若两者均失败，则进入确定性规则降级。3–4 天内不同时维护三套复杂 SDK，优先使用各服务支持的 OpenAI 兼容调用方式，差异放在 Adapter 内。

## 2. V1 调用架构

```text
LangGraph / AgentService
        ↓
LLMProvider
  ├─ OpenAICompatibleCloudProvider
  │    ├─ qwen（默认）
  │    ├─ deepseek（备用）
  │    └─ zhipu（验证后可选）
  └─ RuleOnlyFallback（不调用模型）
```

业务层只依赖统一的 `chat_with_tools()` 和结构化输出接口。供应商、URL、Key、模型名、超时和最大步骤数全部由服务端环境变量提供：

```env
LLM_PROVIDER=qwen
LLM_BASE_URL=replace-with-approved-cloud-endpoint
LLM_API_KEY=replace-me
LLM_MODEL=replace-with-tested-model
LLM_TIMEOUT_SECONDS=30
AGENT_MAX_STEPS=12
```

API Key 禁止写入前端、数据库、代码仓库、截图、录屏和普通日志。切换供应商只能修改服务端配置，不修改菜单、库存和规则业务代码。

## 3. 模型与业务工具边界

模型负责：

- 理解管理员自然语言并生成结构化约束；
- 发现缺少人数、预算或餐次时追问；
- 选择已注册的只读/计算工具；
- 比较三个菜单方案并生成依据清晰的解释；
- 根据管理员修改发起 What-if 重规划。

确定性后端工具负责：

- 库存、保质期和临期判断；
- 过敏原、禁用食材和食品安全硬过滤；
- 单位换算、人数放大、热量与成本估算；
- 库存占用和采购缺口；
- 发布权限、幂等、审计和反馈聚合。

模型不能直接修改库存、提交采购或发布菜单。界面显示工具轨迹和结果摘要，但不展示内部思维链、完整系统提示词或密钥。

## 4. 演示稳定方案

1. 演示前使用与现场相同网络、账号、模型和数据完整跑两遍。
2. 启动时执行一次健康检查，但不消耗核心业务写操作。
3. 主模型调用失败时允许重试一次；仍失败则由管理员切换备用 Provider。
4. 所有云端模型均不可用时进入规则基线，继续完成硬过滤、用量、成本和采购缺口，并明确标注“智能解析/解释暂不可用”。
5. 准备可控故障开关展示降级，不依赖现场真实断网。
6. 禁止把写死的模型回答伪装成实时 Agent 调用；可以使用种子业务数据和固定测试输入。

## 5. V1 评测与放行

至少准备 20 条固定用例，覆盖正常规划、缺人数、花生冲突、库存不足、临期食材、预算变化、人数变化、替代食材、反馈回流、无效 JSON、工具失败、模型超时和管理员拒绝。

放行标准：

- 硬约束过滤固定用例 100% 通过；
- 人数换算与采购缺口固定用例 100% 通过；
- 结构化约束正确率不低于 90%；
- 工具参数必须通过 Pydantic 校验，不合法时不执行；
- 主模型和规则降级链路均至少完整演练两次。

模型选择以项目用例结果为准，不以通用排行榜或参数规模单独决定。

## 6. V2 与 V3

### V2：云端模型工程化

- 继续使用 API，不部署本地模型。
- 完善千问、DeepSeek、智谱 Provider 适配、自动故障转移、调用成本统计和模型评测看板。
- 增加提示词/工具版本管理、审计、缓存和更完整的回归集。
- 根据真实试点的安全要求决定可使用的数据范围。

### V3：私有化可行性验证

- 仅在客户提出数据不出域、网络隔离或国产化部署要求，并具备 GPU/算力与运维条件时评估本地或专有云模型。
- 使用同一 Provider 接口接入经批准的内网 OpenAI 兼容服务。
- 在目标硬件上重新验证工具调用、响应时间、并发、成本、安全和降级能力。
- 是否上线私有模型以项目审批和评测结果为准，不在 V1/V2 提前承诺。
