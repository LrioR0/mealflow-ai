# 数据字典与种子数据规范

| 对象 | 必填字段 | 校验规则 |
| --- | --- | --- |
| 食材 | `key,name,category,default_unit` | `key` 全局唯一，使用规范化小写英文键或拼音键。 |
| 用户 | `email,password_hash,display_name` | 邮箱唯一；国庆版本使用预置演示身份。 |
| 工作区 | `name,kind,owner_id` | MVP 固定使用 `organization`；保留 `personal` 供未来扩展。 |
| 工作区成员 | `workspace_id,user_id,role,status` | `(workspace_id,user_id)` 唯一；MVP 管理端使用 `owner/manager`。 |
| 食堂站点 | `workspace_id,name,service_capacity` | 一个组织可有多个站点；MVP 使用一个总部食堂。 |
| 餐次 | `site_id,name,service_date,expected_diners,status` | `name` 如午餐；人数为正整数；状态为 draft/published。 |
| 库存 | `workspace_id,ingredient_id,quantity,unit,expires_on` | 数量不得小于 0；日期为 ISO 8601。 |
| 菜谱 | `name,servings,duration_minutes,tags,image_source` | 时长为正整数；图片可再分发且标明来源。 |
| 菜谱食材 | `recipe_id,ingredient_id,quantity,unit,optional` | 必需食材用于缺口计算。 |
| 用餐限制 | `workspace_id,type,ingredient_key` | `allergy` 与 `dislike` 均进入硬过滤。 |
| 菜单项 | `meal_plan_id,recipe_id,servings,estimated_kcal_per_serving,score_breakdown` | 热量为结构化估算；保存生成时的解释快照。 |
| Agent 运行 | `workspace_id,meal_service_id,request_text,constraints,state,status` | 保存 LangGraph 状态、版本和运行状态。 |
| 工具轨迹 | `agent_run_id,tool_name,input_digest,status,duration_ms,error_code` | 不保存密钥或完整敏感提示词。 |
| 公共 PC 自助终端 | `workspace_id,site_id,device_id,token_hash,status,last_seen_at` | 设备令牌仅允许 Kiosk 读取已发布菜单和写入反馈。 |
| 匿名反馈 | `device_id,meal_service_id,meal_plan_id,rating,tags,comment,leftover_level,is_suspicious,submitted_at` | 无 `user_id`；评分 1–5，备注限长并脱敏；异常标记不等于自动删除。 |

种子菜谱保存为 `data/seed/recipes.json`，每条须带 `source_name`、`source_url`（无 URL 时注明自制）、`license_note` 与 `created_at`。不得直接抓取或提交不明授权的图片、菜谱正文或营养数据。
