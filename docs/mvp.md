# MVP 验收标准

## 演示数据

准备「示例企业食堂」组织工作区，含管理员 Lrio、员工 Colin、总部食堂和午餐餐次（预计 120 人）。库存为鸡蛋、番茄、土豆、鸡胸肉，其中番茄 2 天内到期；用餐限制包含花生过敏及清淡偏好。种子库至少 20 道可追溯的中式家常菜。

## 必过场景

1. 管理员可切换至示例食堂，维护午餐餐次、预计 120 人、用餐限制及库存。
2. 系统按 120 人放大菜谱用量，计算库存缺口并按品类输出采购清单。
3. 管理员输入“明天午餐，优先消耗临期番茄，清淡”，系统返回菜单、命中限制、临期依据和评分拆解。
4. 菜单不能包含花生等硬性限制，不满足限制时必须返回冲突原因。
5. 管理员能保存并发布菜单；员工模式只能查看已发布菜单和提交评分/剩余反馈。
6. 员工反馈后，管理员可看到对应菜单的评分和剩余情况。
7. Agent 超时或不可用时，规则引擎仍生成正确菜单、采购清单和固定解释。

## 不通过条件

跨工作区读取/修改数据、员工修改库存或发布菜单、过敏原进入结果、批量用量或采购缺口错误、库存为负、页面无错误提示、密钥出现在仓库或前端产物，均为阻断发布问题。
