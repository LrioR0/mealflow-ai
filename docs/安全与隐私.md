# 安全与隐私说明

MealFlow 只收集食堂成员昵称、饮食限制/过敏原、库存和反馈。饮食限制与过敏原属于敏感偏好：仅用于硬过滤和推荐解释，不输出到无关日志或模型提示词之外的第三方。

- LLM 密钥只存在于服务端 `.env`，禁止出现在浏览器、截图、日志、测试夹具和 Git 历史中。
- 后端必须校验数量、日期、单位、预计人数、评分、对象所属工作区与身份角色；客户端校验不能替代服务端校验。
- 营养与替代建议统一标识为估算/一般烹饪建议，不能提供诊断、处方或过敏急救建议。
- Agent 只能调用注册的只读查询工具；保存计划与反馈由显式 API 完成，且要保留操作时间与对象 ID。
- 发现密钥泄露时立即吊销密钥、清理部署环境、用新密钥替换，并通过提交历史删除或轮换暴露的凭据。
