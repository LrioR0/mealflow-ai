# 演示脚本（3–5 分钟）

1. 以管理员身份进入「示例企业食堂」，展示总部食堂、午餐餐次、120 人预计用餐数及花生限制。
2. 打开库存，录入鸡蛋、番茄（两天内到期）、土豆和鸡胸肉，展示临期标记。
3. 输入“明天午餐，优先消耗临期番茄，清淡”，生成 120 人菜单预览。
4. 指出硬约束、临期番茄、批量用量与推荐分数；确认结果中没有花生。
5. 展开采购清单，说明所需量按 120 人换算后减库存得出；保存并发布菜单。
6. 切换为员工身份，查看已发布午餐并提交“4 分、剩余较少”反馈。
7. 返回管理员查看反馈；关闭 LLM 配置或模拟 Agent 异常，重新生成并说明规则引擎仍能返回正确菜单。
