# 贡献与协作指南

分支使用 `codex/<scope>` 或 `feat/<scope>`，一个分支只解决一个可验收用户故事。提交建议使用 Conventional Commits，例如 `feat: add inventory expiry rules`、`test: cover allergy filtering`。

提交 PR 前运行相关测试并填写：目的、变更、验证步骤、风险和截图/API 示例。Lrio 与 Colin 互相审查；涉及数据模型或 API 的 PR 同时更新 `docs/api.md` 与 `docs/数据字典.md`；涉及 Agent State、节点、工具或提示词的 PR 同时更新 `docs/Agent设计.md` 和固定评测用例；涉及评分终端的 PR 验证连续两次提交后数据已重置。禁止提交 `.env`、设备令牌、本地数据库、构建产物、受版权限制的菜谱或图片。
